# Idea Vault

아이디어와 프로젝트 구상을 Markdown 문서로 축적하고 관리하는 저장소입니다.

## 탐색

- [전체 색인](INDEX.md)
- [미분류 아이디어](inbox/README.md)
- [분류별 아이디어](ideas/README.md)

## 기록 원칙

- 사용자가 명시적으로 확정한 내용과 보조적인 해석·제안을 구별합니다.
- 원문 내용과 의도를 임의로 변경하지 않습니다.
- 아이디어가 등록되면 주제에 맞는 폴더와 문서를 만들고 전체 색인을 갱신합니다.
- 분류가 아직 불명확한 아이디어는 `inbox/`에 보관합니다.

분야별 폴더는 실제로 등록되는 아이디어를 기준으로 생성합니다.
